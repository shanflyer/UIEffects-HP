# Contributing

The package supports **Unity 2022.3 LTS and Unity 6**. The minimum supported version is **2022.3**. The repository root is the UPM package, with `package.json`, `Runtime`, `Editor`, `Tests` and `Samples~`.

For development, create a separate Unity project and use Package Manager's install-from-disk option to select this repository's root `package.json`. Keep the UGUI version supplied by the editor. Do not open this repository as a Unity project.

Include the Unity version and minimal reproduction steps when reporting issues. Do not commit generated caches, captures or local experiments.

See [package validation](Documentation~/Validation.md) for results and testing instructions.
