# 性能行为与测量

实现入口位于 `Runtime/UIEffectRenderer.cs`、`CanvasEffectOutput.cs` 及其 Bridge 分部文件。以下描述当前代码，不是待实现的优化规划。

## 全局开关

配置入口为 **Project Settings → UI Effects HP**，界面使用英文，各项提供悬浮说明。设置保存在 `Resources/UIEffectSettings.asset`；未创建资产时使用相同的内置默认值。默认 `updateRatePercent = 100`、`staggerBaking = true`、`mergeRenderers = true`、`earlyCull = 1`、`staticMeshCache = true`、`fastBindingMode = false`、`meshSharingEnabled = true`。

原有静态属性赋值仍可覆盖项目配置，但不写回资产。设置界面检测到覆盖时显示实际运行值，可点击按钮或调用 `UIEffectRenderer.ResetPerformanceOverrides()` 恢复项目配置。进入播放模式会清除覆盖，包括禁用 Domain Reload 的情况；测试控制器随后仍可按其参数重新覆盖。项目附带评测场景的合并、裁剪和暂停缓存启动值也已改为上述默认值。

| 设置 | 实际行为与边界 |
| --- | --- |
| `mergeRenderers` | 将同一 UIEffectRenderer 的兼容粒子本体和 Trails 烘焙后合并为 UI 输出；各源仍分别调用 BakeMesh / BakeTrailsMesh。主要减少输出节点和提交，不把多个系统变成一次原生烘焙。 |
| `updateRatePercent` | 1–100 的整数百分比，默认 100（每帧）。50 表示平均每两帧更新一次，25 表示平均每四帧一次。按实际帧计数调度，不依赖固定 Hz 或 FPS 估计；帧率下降时仍保持比例。新增、失效和裁剪恢复可立即刷新。 |
| `staggerBaking` | 默认 true，在 `updateRatePercent < 100` 时为效果自动分配稳定偏移；共享粒子同组同步，独立桥接使用各实例偏移。false 恢复共同时间刻度。无需手填 ID。 |
| `earlyCull` | 0 关闭可选提前裁剪；1 在透明隐藏/已判完全裁剪时减少几何工作，粒子模拟继续按调度推进；2 在 alpha 隐藏条件下再暂停粒子模拟。 |
| `staticMeshCache` | 缓存暂停且相关变换/Canvas 状态未变的粒子输出；不等于冻结独立 Mesh/Line/Trail 或遮罩。外部修改粒子需显式失效。 |
| `meshSharingEnabled` | 默认允许；组件仍默认 Independent。Automatic / Producer / Consumer 等角色按兼容性分组。关闭总开关后各实例独立模拟，SimulationOnly 继续隐藏输出；切换可能改变播放相位。 |
| `fastBindingMode` | 跳过常规绑定复核；改材质、贴图、trail 或其他绑定输入后需 `MarkBindingDirty()`。不是渲染特性的开关。 |

编辑器预览不按运行时 updateRatePercent 限频；暂停粒子是否重复生成输出还取决于静态缓存。粒子 Trails 正常跟随本体烘焙帧，避免独立推进模拟。降频累积实际 scaled/unscaled 时间后消费，不代表逐帧更新有完全相同的模拟轨迹或观感。

错峰按 0、1/2、1/4、3/4 等周期偏移分散注册的效果，共享组在生产者切换时保留偏移。每个效果内部的粒子输出保持同步，Trails 跟随本体；独立桥接按实例错开。跳过的帧累积 scaled/unscaled 模拟时间，到期一次消费。切换百分比或错峰设置保留待消费时间。

例如 `UIEffectRenderer.updateRatePercent = 50`：游戏实际 60 FPS 时平均每秒更新 30 次，实际 30 FPS 时平均每秒更新 15 次。保持 `staggerBaking = true` 时，不同效果分散到相邻帧；100% 时每帧更新。首次显示、失效和隐藏恢复允许立即刷新，不能保证这些瞬时峰值被摊平。

这是按效果数量分散的时间调度，没有按实测 Bake 耗时加权，也不是每帧硬预算；单个大效果不会拆分。需要结合 Canvas 批处理一起测量，不能把调用数量均匀等同于 CPU 耗时均匀。

## 合并的实际检查范围

`CanMerge()` 检查粒子共享材质与有效贴图、Trail 材质/贴图兼容性，以及 SpriteMask interaction。Material property synchronization、源混合排序、共享组布局及顶点超限等条件也会影响合并或回退。

合并还检查 Render Mode 和顶点流一致性；材质声明属性存在 MPB 覆盖时保守回退。Unity 自身也会给粒子 Renderer 携带内部 MPB，不能仅凭 `HasPropertyBlock()` 就禁用合并。Shader 未声明在 Properties 中的自定义 uniform 不在此检查范围内，使用此类 MPB 时应关闭合并；任意 MPB 也不会自动迁移成 UI 材质。

自动共享以来源标识为基础，并复核粒子顺序、材质、顶点流、Mesh 和变换等。检查有 CPU 成本，稳定布局会复用缓冲，不按帧创建新的分组键。它不保证运行时任意模块修改都能自动判断为不同模拟；独立模拟应关闭共享。

Mesh Sharing 与合并是不同功能：前者减少重复效果的模拟和几何生成，后者减少同一效果的 UI 输出数量。二者都不能保证一个 Draw Call。

## 分组表跨帧复用

分组成员和消费者槽位表在稳定帧复用。每帧检查参与共享的状态、组 ID、输出数量和有效 Renderer 引用；成员增删、自动拆组/重新入组、输出禁用/销毁/替换、合并回退等改变结构时重建。当前结构变化会重建整张分组表，不是只重建单组。

主实例优先级和整组可见性仍逐帧判断，不缓存成永久结果。提交消费者前再次核对所属组、有效性和输出引用，过滤当帧失效的对象。生产者失败或缺失时清空同组粒子输出，独立桥接不受该清空影响；后续帧重新尝试准备。异常日志按实例去重。

`UIEffectProfiler.completed.groupPlanRebuilds` 表示该帧结构表重建次数；稳定帧应为 0，合并回退可能使同帧多次重建。结构核验仍为 O(效果数 + 共享输出数)，自动共享的兼容性检查仍保留；这项优化减少列表重填和分组建表，不消除所有遍历，也不直接减少 BakeMesh 次数。缓存增加少量持久引用内存，目前没有实测整帧加速比例。

## 自动减少的工作

### 桥接网格

Mesh/Line/Trail 比较顶点、法线、切线、颜色、UV0–7、索引、拓扑及转换状态。未变化时跳过后续 CombineMeshes、几何处理和 SetMesh，材质动画继续更新。

比较仍为 O(顶点数 + 索引数)，并占用复用缓冲；扩容可能分配。Line/Trail 在到期帧仍须先 BakeMesh 才能比较结果。该缓存不表示所有活动 ParticleSystem 都会跳过 BakeMesh。

### 不可见输出

共享组按消费者可见性判断，仍有可见副本时必须继续提供粒子结果。禁用 Canvas 的消费者不计为可见输出；独立桥接会停止更新，恢复后读取最新源。

完全裁剪保留约 0.1 秒一次的几何探测，避免旧 Bounds 阻止恢复；因此不是永久零工作。没有实现对所有移出屏幕对象的独立 viewport 剔除。Line/Trail 原生组件继续采样轨迹，Full Cull 不会把整个原生特效系统停掉。

### SpriteMask

同轮更新按源 Renderer 复用遮罩解析结果，粒子 body/trail 及 SpriteRenderer 的接管和绘制共用解析缓存；场景查询每轮按需最多一次。几何与材质分别失效，纯参数变化不反复提交网格。原地修改 Sprite 几何仍需通知。

隐藏时停用对应写入节点，可见时恢复。遮罩关系不做跨帧成员缓存，以便识别外部增删、移动和排序变化。

## 指标

`UIEffectProfiler` 默认记录计数；通过 `BeginDetailedTiming()` 返回的 IDisposable 请求启用耗时统计，使用结束后释放。详细计时本身有额外开销。

关注 bake/combine/submit 的耗时与调用数，并结合 `bridgeCacheHits`、`bridgeCompareMs`、`maskMeshSubmissions`、`maskResolveCacheHits`。`submitMs` 只覆盖调用阶段，不包含后续 Canvas 批处理或 GPU 执行时间。

评测时固定资产、可见状态、屏幕尺寸、共享配置和画质；分别观察 CPU、Canvas 与 GPU。不能把 BakeMesh 时间全部视为相对原生粒子增加的净成本，原生粒子也需要准备渲染几何。

当前没有发布真机 FPS 提升或固定成本比例。验证结果见[验证记录](Validation.md)。

## 架构边界

本实现仍通过 Mesh 向 CanvasRenderer 提交。没有实现直接复用 Shuriken 原生 GPU 缓冲、向 Canvas 内部插入自定义 Draw、GPU 粒子或自定义粒子几何生成。

独立效果已支持连续兼容段合并；共享效果仍使用统一的合并或分离槽位。预算调度和独立 viewport 剔除尚未实现。是否开发应由测量结果决定；旧规划中的建议不属于当前功能承诺。

## 1.0 核心优化

单源的坐标转换严格为单位矩阵时，直接烘焙到生产者拥有的 Mesh，省掉中间 Combine。`directBakeOps` 记录次数。普通变换仍调用 CombineMeshes，未启用未经验证的自定义 Job 顶点转换。

几何加工由 GeometryProcessor 统一处理；修改器每次加工只查询一次。动态增删修改器仍能被检测，没有假设组件永久不变。颜色校正与修改器同时使用时，共用颜色读取缓冲。

每个源的模拟会话由绑定持有；模拟阶段不修改源 Transform，也不根据分辨率变化重写原生粒子位置。共享调度跨帧复用成员与消费者槽位表，结构发生变化才重建。自动分组的结构比较仍保留，任意运行时粒子模块变化不自动代表独立模拟。

生产者拥有输出 Mesh 会增加持久内存；本版本没有承诺固定 FPS 提升。

## 配置与源数据维护

- 配置相同值赋值不使几何缓存失效；有效变化统一通知缓存，动画修改与 Inspector 修改也走校验路径。
- 子发射器父级索引在绑定时按源与边遍历一次，然后按键查询；编辑器预览按次重建。运行时关系变化需显式刷新绑定。
- 吸引器持有可复用的粒子读回数组；模拟器不再读取并重写粒子坐标。多个吸引器需要读回时仍会增加持久内存。
- 烘焙不修改 Shape，零轴不再自动修正。删除无调用的旧排序辅助函数不计为运行时性能收益。

这些是工作量和生命周期上的调整，尚无本轮整帧耗时或真机性能对照。

## 输出绑定与坐标计算优化（2026-09-28）

- 裁剪矩形使用本地到根 Canvas 的组合矩阵，把 XY 矩形中心与半尺寸映射到目标空间，替代四角的两级变换与边界扫描。保留原来的局部 z=0 投影语义。
- Local / World / Custom 模拟空间直接构造缩放与平移矩阵。World 使用偏移 p − scale×p，移除与运行时等价的编辑器重复分支。
- 吸引器每次更新读取一次目标位置，提前计算半径平方、延迟比例与运动类型；通过统一坐标映射的逆矩阵转换目标。仍逐源核对层级归属，没有引入可能过期的跨帧父级缓存。
- 输出刷新先生成完整描述，再识别可保留的槽位；先统一释放变化输出的源抑制状态，之后绑定新输出。同槽位、同源、同 Trails/子发射器/材质等绑定的输出保留模拟历史；合并输出也复用原数组，独立桥接保留原始抑制状态。
- 显式 RefreshSources 仍使保留输出的几何失效，以便读取外部修改；它不再无条件重置未变化输出的模拟历史。需要重新播放时调用 Play。来源移动到不同槽位、合并布局改变或绑定失效时仍会重置受影响输出；不是任意重排都无损保留历史。
- 输出描述与合并来源列表复用容量，增加少量实例持久内存；未实现对所有来源的全局模拟历史迁移。关闭源排序会恢复输出槽位的绘制顺序。
- Sprite UV0 要求由源绑定持有并在释放时按条件恢复；烘焙视图自动匹配根 Canvas 的实际尺寸或绑定相机，复用内部相机；视图变化会使暂停网格缓存失效，并参与共享分组匹配。禁止把效果自身或祖先作为新粒子实例，校验发生在旧对象停用之前。

这些优化不改变原生 BakeMesh 实现。最近重构只完成编译与静态检查，旧回归结果不能代表当前版本；没有据此声明固定 FPS 或整帧耗时收益。

## 扩展 Renderer 桥接

Mesh/SkinnedMesh 按材质槽输出，每槽有独立的几何比较、转换与 UI 提交；不会因为一个来源有多个材质而重复烘焙同帧蒙皮快照。SkinnedMeshRenderer 的 CPU BakeMesh 成本仍存在。源输出引用共享抑制租约，部分输出重绑不会提前恢复原生绘制。

Sprite 在来源 Sprite、贴图、颜色、翻转、尺寸、绘制模式或平铺参数变化时重建几何；移动只改变坐标转换。顶点/UV/索引数组在来源变更或显式失效时读取，稳定帧复用缓存。超过预算的平铺拒绝生成，避免尺寸异常造成无界循环或分配。

这些扩展会增加材质槽数量对应的输出节点、网格与快照内存。原生绘制与 UI 输出的像素对照只验证行为，不代表性能提升。

## 适配实现替换后的成本边界

移除全局可写烘焙 Mesh，单输出的中间网格在首次非单位变换烘焙时分配并随输出销毁；单位变换直烘焙不分配该网格。多个输出可能增加持久内存。材质变体按真实对象引用共享，移除 Editor JSON 序列化哈希；解析时复制源材质属性。上述是实现变化，未据此声明性能提升。
